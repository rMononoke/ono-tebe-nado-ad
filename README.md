# Проектная работа «Оно тебе надо»

Одностраничный сайт (лендинг) онлайн-аукциона необычных вещей «Оно тебе надо — аукцион вещей, в которые никто не верил».

Проект выполнен в рамках курса «Фронтенд-разработчик» от Яндекс Практикума (Спринт 2: «Вёрстка. Семантика и лейаут»).

## Стек технологий

- HTML5 (семантическая разметка: `<header>`, `<main>`, `<section>`, `<article>`, `<nav>`, `<address>`, `<footer>`)
- CSS3:
  - Flexbox и CSS Grid Layout
  - БЭМ-нейминг
  - Абсолютное и относительное позиционирование
  - Типографика и кастомные шрифты (семейство Raleway)
  - Pixel Perfect соответствие макету Figma

## Структура проекта

```text
├── fonts/          # Файлы шрифтов Raleway (woff, woff2) и fonts.css
├── images/         # Изображения, векторная графика SVG
├── styles/
│   ├── global.css  # Базовые стили и сбросы
│   └── style.css   # Стили проекта
├── index.html      # Главная страница
└── README.md
```
